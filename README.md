# NDI ScreenCast

Android-приложение для передачи экрана или отдельного приложения и системного звука по NDI High Bandwidth.

[Скачать APK](https://github.com/Mike-iLeech/NDIScreenCast/releases/latest) · [GitHub Releases](https://github.com/Mike-iLeech/NDIScreenCast/releases)

## Возможности

- Android 10+, ARM64 / ARMv7 / x86_64.
- Захват всего экрана; на Android 14+ — выбор отдельного приложения через системный диалог.
- До 720p или 1080p, выбор 30/60 кадров/с. Реальная частота зависит от устройства и сети.
- Системный звук: PCM16, стерео, 48 кГц; микрофон не используется. Android захватывает только звук приложений, разрешивших запись. Звук других подходящих приложений тоже может попасть в поток.
- Таймер, цельная зелёная кнопка до запуска и красная во время эфира, иконка приложения.
- Настройки: отображение битрейта (изначально скрыт), автообновление (изначально включено), ручная проверка обновлений.
- Автообновление из публичных GitHub Releases: проверка при открытии и в фоне с интервалом 24 часа, автоматическая загрузка APK, установка с подтверждением Android. Во время эфира установка не предлагается.

Телефон и приёмник должны находиться в одной доверенной локальной сети. На компьютере выберите источник в NDI Studio Monitor или OBS с DistroAV. При переподключении приёмника может потребоваться повторно выбрать источник.

## Обновления

Приложение читает `releases/latest/download/update.json`. В манифесте находятся числовой `versionCode`, `versionName`, `apkUrl` и `sha256`. APK загружается только из Releases этого репозитория по HTTPS. Перед установкой проверяются SHA-256, идентификатор приложения, увеличение versionCode и совпадение сертификатов подписи с установленной версией.

Android может запросить разрешение «Установка неизвестных приложений» для NDI ScreenCast. Тихая установка без подтверждения не используется. Если автообновление выключено, периодическая задача отменяется; ручная проверка остаётся доступной.

Битрейт — приблизительная исходящая скорость приложения по Android TrafficStats, включая служебные пакеты и всех получателей NDI. Это не отдельная статистика видеокодека. Без получателей обычно отображается около нуля. Показатель скрыт по умолчанию.

## Сборка на Windows

1. `./setup.ps1` — скачать Android SDK/NDK, JDK (если отсутствует JAVA_HOME) и официальный Android NDI SDK в папку `tools/`. Применяются условия лицензий этих SDK.
2. Установить переменную `NDI_SIGNING_PASSWORD` и положить свой ключ в `signing/release.jks` (alias `ndicast`), либо позволить скрипту создать новый ключ для собственной сборки.
3. `./build.ps1` — собрать, подписать и проверить APK в `dist/`.

Для обновлений официальной сборки требуется исходный локальный ключ. Самостоятельная сборка с другим ключом не обновляет установленную официальную версию. Ключ, пароль, SDK, временные файлы и APK исключены из Git. Локальная настройка пароля поддерживается в игнорируемом `signing/local.ps1`. Секреты не следует помещать в исходники или GitHub Actions.

GitHub Actions компилирует приложение и проверяет подпись/выравнивание с отдельным тестовым ключом; официальный релиз подписывается сохранённым локальным ключом владельца. CI не публикует свои APK.

## Публикация следующего релиза

После изменения кода увеличить `versionCode` и `versionName` в AndroidManifest.xml, обновить имя APK в build.ps1, пройти независимое ревью и проверки. Запустить `./build.ps1`, затем `./release.ps1`: он создаст `dist/update.json`. Опубликовать APK и update.json одним GitHub Release с тегом `v<versionName>`, направленным на проверенный коммит. Пометить релиз как Latest. Ключ подписи менять нельзя.

Код публикуется через ветку и PR; PR объединяет владелец. Начальная базовая ветка `bootstrap` содержит только описание репозитория.

## Проверка

APK собирается для трёх архитектур; apksigner и zipalign проверяются скриптом сборки. Интерфейс, запуск и остановка захвата, системный звук и таймер проверялись в эмуляторе Android 15. Сквозная передача на реальный NDI-приёмник и реальная частота 60 кадров/с не измерялись.

## NDI и сторонние компоненты

NDI® — торговая марка Vizrt NDI AB. [ndi.video](https://ndi.video). Используется официальный Android NDI SDK 6.3.2. Лицензия NDI SDK и уведомления сторонних компонентов включены в APK (`assets/`). Исходники и библиотеки самого SDK в Git не публикуются; setup.ps1 скачивает их с официального сервера.

Центрированные подписи и внутренние отступы выпадающих списков; логотип в заголовке; подсказка «После запуска трансляции…».
